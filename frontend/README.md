# Price Counter - Frontend

React-Based Price Calculator для розрахунку вартості будівельних робіт з категоризацією та динамічною фільтрацією.

## Огляд проєкту

**Стек технологій:**
- React 19
- Vite 8
- jsPDF + html2canvas (для експорту PDF)
- ESLint (code quality)

**Основні можливості:**
✅ Динамічні випадаючі списки (категорії → підкатегорії → роботи)  
✅ Числовий інпут для площі з валідацією  
✅ Автоматичний розрахунок кінцевої ціни (ціна/м² × площа)  
✅ Таблиця з доданими роботами  
✅ Кнопки друку та експорту PDF  
✅ Адаптивний дизайн (мобільні пристрої, таблети, ПК)

## Встановлення та запуск

### Вимоги

## Компоненти

### PriceCalculator
Головний компонент, що управління станом додатку:
- Завантажує категорії з API
- Керує списком доданих робіт
- Надає функції друку та експорту PDF

### JobForm
Форма для вибору роботи та введення площі:
- Каскадне заповнення списків (категорія → підкатегорія → робота)
- Валідація числового інпуту для площі
- Кнопка "Додати" для додавання роботи до таблиці
- Автоматичне очищення форми після додавання

### JobTable
Таблиця для відображення доданих робіт:
- Колонки: Категорія, Підкатегорія, Робота, Ціна/м², Площа, Кінцева ціна
- Кнопка видалення для кожного рядка
- Вивід загальної суми всіх робіт
- Оптимізація для друку (приховань кнопки видалення)

- Позначка ландшафтної орієнтації

## Розробка

### Додання нової роботи до mock-даних
Відредагуйте масив `mockCategories` у `src/services/api.js`:

```javascript
{
  id: 1,
  name: 'Категорія',
  subcategories: [
    {
      id: 1,
      name: 'Підкатегорія',
      tasks: [
        { id: 1, name: 'Робота', pricePerM2: 100 }
      ]
    }
  ]
}
```

### Підключення справжнього API
Оновіти функції у `src/services/api.js`:
1. Замінити mock-дані на fetch запити
2. Налаштувати VITE_API_URL змінну оточення
3. Обробити помилки та loading стани
